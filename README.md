# Portafolio de Nicolás Escudero

Presentación estática de un proyecto académico de bases de datos relacionales con PostgreSQL.

## Visualización

Abra `index.html` en un navegador. El sitio no requiere instalación ni dependencias externas. También puede servir esta carpeta mediante cualquier servidor de archivos estáticos.

## Contenido

- `index.html`: perfil académico, presentación del proyecto y visor de código.
- `assets/avatar.svg`: avatar de iniciales NE.
- `proyectos/prueba-sql/`: solución SQL, instrucciones, desarrollo técnico y capturas de resultados.

El sitio solo presenta archivos estáticos. PostgreSQL debe ejecutarse por separado siguiendo el README del proyecto. Todos los datos del ejercicio son ficticios.
